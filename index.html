🔥 Koneksi Firebase Firestore

Sinkronisasi data realtime — akses dari perangkat mana pun

⚪ Lokal

📖 Panduan Setup Firebase (klik untuk buka)
Langkah 1 — Buat Project Firebase
Buka console.firebase.google.com → klik "Add project" → beri nama (misal: panen-dividen) → Continue → Disable Google Analytics → "Create project"

Langkah 2 — Aktifkan Firestore Database
Di sidebar kiri → Build → Firestore Database → klik "Create database" → pilih "Start in test mode" → pilih region asia-southeast1 (Singapore) → "Enable"

Langkah 3 — Aktifkan Anonymous Auth
Di sidebar → Build → Authentication → klik "Get started" → tab "Sign-in method" → klik "Anonymous" → toggle Enable → "Save"

Langkah 4 — Dapatkan Config
Di sidebar → ⚙️ Project Settings → scroll ke bawah → klik icon </> (Web) → register app (nama bebas) → copy kode firebaseConfig

Langkah 5 — Atur Firestore Rules
Di Firestore → Rules, paste rules berikut lalu klik "Publish": 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}
⚠️ Penting: Rules di atas memastikan hanya Anda yang bisa baca/tulis data Anda sendiri.
